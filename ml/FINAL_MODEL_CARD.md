## 1. Model Overview

The `sih26165_sif_ml_predictor` is a specialized, lightweight natural language processing baseline designed to identify Serious Injury and Fatality (SIF) Precursors directly from free-text workplace incident descriptions. Selected through empirical benchmarking across Phase 6.1 (TF-IDF), Phase 6.2 (Sentence Transformer), and Phase 6.3 (Hybrid Fusion), this pure TF-IDF + Logistic Regression pipeline demonstrated the highest classification fidelity, lowest error count, and greatest interpretability.

### Primary Purpose
* **Input**: Unstructured workplace safety narrative (`normalized_narrative`).
* **Output**:
  * Binary classification (`ml_label` $\in \{\text{"YES"}, \text{"NO"}\}$).
  * Continuous SIF precursor propensity score (`ml_score` $\in [0.0, 1.0]$).
  * Feature-level log-odds explanations (`positive_evidence`, `negative_evidence`).

## 2. Model Architecture & Pipeline

```
normalized_narrative (Raw String)
        │
        ▼
Exact Normalization & Accent Stripping (Unicode, Lowercase)
        │
        ▼
TF-IDF Vectorizer (ngram_range=(1,2), min_df=2, max_features=5000, sublinear_tf=True)
        │
        ▼
4,886-dimensional Sparse Feature Vector
        │
        ▼
Logistic Regression Classifier (C=100.0, class_weight='balanced', solver='lbfgs')
        │
        ▼
Decision Thresholding (tau = 0.59 Locked)
        │
        ▼
Prediction Output: YES (SIF Precursor) / NO (Non-SIF Precursor) + Lexical Evidence
```

## 5. Hyperparameter & Decision Threshold Selection

* **Regularization Parameter $C$**: Selected via validation-only sweep across $C \in [0.01, 0.1, 1.0, 10.0, 100.0]$.
  * **Selected $C = 100.0$** achieved peak Validation Macro F1 (0.8934) and ROC-AUC (0.9804).
* **Decision Threshold $\tau$**: Selected via validation-only fine-grained sweep across $\tau \in [0.30, 0.70]$ in $0.01$ steps.
  * **Selected $\tau = 0.59$** achieved peak Validation Macro F1 (0.9196) and peak YES Recall (0.9833).
  * Formally locked prior to untouched test evaluation.

## 7. Explainability & Interpretation

The predictor provides real-time lexical explainability based on linear model mechanics:
$$\text{Contribution}_j = x_j \cdot w_j$$
where $x_j$ is the TF-IDF feature value in the input narrative and $w_j$ is the trained model coefficient.

* **Positive Evidence**: Non-zero n-grams that increase the SIF log-odds (e.g., `"feet"` $+0.72$, `"employee fell"` $+0.62$, `"beam"` $+0.40$).
* **Negative Evidence**: Non-zero n-grams that decrease the SIF log-odds (e.g., `"heart attack"` $-1.90$, `"collapsed"` $-0.82$, `"hand tool"` $-0.45$).
* **Constraint**: Features are displayed **only if they explicitly appear in the narrative**.

## 8. Limitations & Known Failure Cases

1. **Hierarchical Tool-vs-Machine Precedence (`SIR_1065535`)**:
   * *Incident*: Clearing snow with a hand wrench from a conveyor belt.
   * *Limitation*: The bag-of-words model responds strongly to machine tokens (`"conveyor belt"`), predicting a false positive even when the initiating mechanism was an unpowered manual tool.
2. **Ambiguous Low-Height Falls with Heavy Machinery (`SIR_1130964`)**:
   * *Incident*: Exiting crane, walked on tracks, fell two feet off tracks.
   * *Limitation*: The token `"two feet"` strongly associates with low-risk slips in general distributions, overpowering the crane superstructure elevation context.
3. **Same-Level Slips with Heavy Structural Loads (`SIR_963496`)**:
   * *Incident*: Slipped on ice while carrying a 30-foot industrial pipe.
   * *Limitation*: Common slip terms (`"slipped and fell"`, `"ice"`) dilute the gravitational exposure of the structural pipe load.
4. **Verbose Incident Narratives with Diluted Hazards (`HSE_220850069_3523`)**:
   * *Incident*: 92-word description of holding an energized 480V cord while walking to stairs and touching a railing.
   * *Limitation*: Lengthy descriptions of walking and railings push positive probabilities near the boundary ($P=0.5008$).
5. **Non-Industrial Settings (`SIR_974353`)**:
   * *Incident*: Church sanctuary Easter platform steps.
   * *Limitation*: Religious and domestic vocabulary suppresses industrial workplace hazard features.
